# Site do Kit Currículo ATS

Esta pasta é o que vai para o Netlify. Arraste **só esta pasta `site`** em app.netlify.com/drop.

1. Em `config.js`, preencha `metaPixelId`, `product.checkoutUrl`, `support.email` e `legal`.
2. Publique e confira o Pixel com a extensão Meta Pixel Helper (PageView, ViewContent e InitiateCheckout).

O passo a passo completo está no documento "Plano de lançamento: Kit Currículo ATS".
